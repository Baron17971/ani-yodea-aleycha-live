# אני יודע עליך — סקר מורים חי

אפליקציה קצרה ואנונימית למפגש קהילת מורים.

- המנחה פותח מפגש ומקבל קוד בן 5 ספרות + QR.
- כל מורה חושב על תלמיד אחד ומשיב על 8 שאלות: „יודע / לא יודע”.
- התוצאות מתעדכנות בזמן אמת ומוצגות גם בתצוגת מקרן.
- אין שמות ואין הרשמה.
- ניתן לנעול/לפתוח הצבעה ולפתוח מפגש חדש.

היישום סטטי ומשתמש ב-PeerJS לחיבור חי בין מכשירים וב-QRCode ליצירת QR. המנחה צריך להשאיר את דף המפגש פתוח בזמן הפעילות.
